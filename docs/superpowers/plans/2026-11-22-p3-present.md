**Files:**
- Create: `plugins/orchestra/scripts/consistency_audit.py`, `tests/unit/test_consistency_audit.py`

**Interfaces:**

  - Checks and messages (spec §8.1):
    - `E-CONS block <file>:<line>: "tỷ lệ tái nhập viện" is 85% here but 86,3% in <file2>:<line2>` — key = 2–4 content words immediately before the number (lower-case, NFC, punctuation stripped, stop words removed: vi {là, của, có, và, được, trong, với, ở, cho, các, những, một, này, =, :} en {is, was, of, the, a, an, in, at, to, =, :}); compare only same unit class (percent vs percent, count vs count, plain decimal vs decimal); a value equal at the shorter printed precision is NOT a conflict (85% vs 85,0%).
    - Sample size: `≈`, `~`, `khoảng`, `xấp xỉ`, `about`, `approximately` followed within 3 tokens by an integer and within 6 tokens by a participant word (bệnh nhân, người bệnh, đối tượng, ca, trường hợp, patients, participants, subjects, cases) or preceded by `n` / `cỡ mẫu` / `sample size` → `E-CONS block … sample size must be a whole number rounded up, not "≈26"`; a decimal participant count (`n = 26,65 bệnh nhân`) → same block.
    - Date ranges: patterns `MM/YYYY`, `DD/MM/YYYY`, `tháng M/YYYY`, `tháng M năm YYYY`, `YYYY-MM(-DD)`, `Month YYYY`, joined by `–`, `-`, `đến`, `to`, `until`; normalised to (start, end) at month precision; two ranges with the same start and different ends (or same end, different starts) anywhere in the files → block, naming both places.
    - Abstract vs results: a number in a file whose name contains `abstract` and which appears neither in any other audited file nor as a ledger value (any part, as printed) → warn.
    - Percent sum: a Markdown table with a row whose first cell is `Tổng`/`Total`/`Chung`: for each column whose cells are percentages (or `n (x%)`), the other rows' percentages must sum to the total row's within 0.5 → else warn.
    - Terms: `project.yaml → terms:` mapping (`preferred: [variant, …]`, YAML block mapping parsed with the existing minimal reader or a small parser in this script) plus built-in `{"HbA1c": ["HbA1C", "Hba1c", "HBA1C"], "đái tháo đường": ["tiểu đường"]}` → warn per variant occurrence.
  - Escape: a line containing `<!-- cons-ok: <reason> -->` is skipped for all checks.
  - Exit 1 when any block; summary `consistency_audit: <b> block, <w> warn`.
- Importable: `consistency_audit.audit(project: Path, files: list[Path] | None = None, lang: str | None = None) -> list[tuple[str, str, str]]` (severity, location, message).
