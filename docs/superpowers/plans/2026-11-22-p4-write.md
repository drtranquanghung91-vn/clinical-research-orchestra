**Tech Stack:** Python 3.10+ (standard library only for every script in this plan), Markdown skills and references, JSON item lists, `unittest`, Claude Code CLI (`claude -p`) for scenarios and the end-to-end run.

### Task 1: `build_docx.py` additions (spec 6.2)

**Files:**
- Modify: `plugins/orchestra/scripts/build_docx.py` (full replacement below), `tests/unit/test_build_docx.py` (append tests)

**Interfaces:**
- CLI: `build_docx.py <a.md> [<b.md> …] <out.docx> [--project DIR] [--template FILE.docx]`. At least one input and an output ending `.docx` (else exit 2). Inputs joined in order with one blank line; each input's image paths are made absolute against that input's folder first.
- Importable (used by `assemble.py`): `build(md_text: str, settings: dict, base_dir: Path | None = None, template: Path | None = None) -> bytes`, `settings_from_project(project) -> dict` (unchanged), `template_from_project(project) -> Path | None` (`project.yaml → institution.template`, relative to the project; empty → None), `png_size(data: bytes) -> tuple[int, int]` (raises `ValueError` for a non-PNG), `absolutize_images(text, base) -> str`.
- Markdown additions: `#### ` → `Heading4`; `- `/`* ` lines → `ListParagraph` with `numId 1` (bullet "–"); runs of `N. ` lines → `ListParagraph` with a new `numId` per run, `startOverride` = first number, marker text removed; a line `![Caption](file.png)` → inline PNG paragraph (style `Figure`) then the caption paragraph (style `FigureCaption`) below; a line `{TOC}` → TOC field `TOC \o "1-3" \h \z \u` (`w:dirty="true"`) and `word/settings.xml` with `<w:updateFields w:val="true"/>`; every document gets `word/footer1.xml` (centred `PAGE` field) referenced from `sectPr`, `word/numbering.xml`, `word/settings.xml`.
- Image size: width = text-block width (page width − left − right margin, twips × 635 EMU), height = width × h / w (integer division); if taller than 90% of the text-block height, both are scaled down to that height.
- Template: `styles.xml` taken verbatim, then every style id of ours that the template lacks (`Normal`, `Heading1`–`Heading4`, `Caption`, `FigureCaption`, `Figure`, `TableNote`, `ListParagraph`) is appended before `</w:styles>`; the template's last `<w:sectPr>…</w:sectPr>` replaces ours after removing `headerReference`, `footerReference`, `printerSettings` and attributes in namespaces other than `w:`; our footer reference is inserted first. A missing or unreadable template → exit 2.

```python
def png(w: int, h: int) -> bytes:
    raw = b"".join(b"\x00" + b"\xff\x00\x00" * w for _ in range(h))

    def chunk(t: bytes, d: bytes) -> bytes:
        return struct.pack(">I", len(d)) + t + d + struct.pack(">I", zlib.crc32(t + d) & 0xFFFFFFFF)
    return (b"\x89PNG\r\n\x1a\n" + chunk(b"IHDR", struct.pack(">IIBBBBB", w, h, 8, 2, 0, 0, 0))
```

````python
#!/usr/bin/env python3
"""Build a .docx from a Markdown subset (standard library only).

  python build_docx.py <input.md> [<more.md> ...] <output.docx> [--project DIR] [--template FILE.docx]

Supports #/##/###/#### headings, paragraphs with **bold** and *italic*, "- " bullets and "1. " lists (Word list
numbering; each run of numbered lines restarts at its first number), pipe tables with a caption line above
(Bảng 3.1. … / Table 1. …) and Nguồn:/Note: lines below, PNG images on their own line
`![Hình 3.1. Caption](figure.png)` (fitted to the text width, aspect kept, caption below), a `{TOC}` line
(table-of-contents field; Word fills it on open, "Update field"), \\newpage, and a centred page-number footer.
Several inputs are joined in order with a blank line; image paths are relative to their own .md file.
Page setup from project.yaml → docx (font, size_pt, line_spacing, margins_cm [top, bottom, left, right]);
defaults: Times New Roman 13 pt, 1.5 lines, 2/2/3/2 cm, A4. --template FILE.docx (default: project.yaml →
institution.template, relative to the project) replaces the styles and the page setup with the template's
styles.xml and last w:sectPr; content still comes from the Markdown (templates/thesis/README.md).
Approach adapted from Amelia Le's md2docx.py.
Exit codes: 0 = written; 2 = usage or I/O error (missing input, image or template; image not PNG; output not .docx).

def png_size(data: bytes) -> tuple[int, int]:
    if data[:8] != PNG_SIG or data[12:16] != b"IHDR":
        raise ValueError("not a PNG file (only PNG images are supported)")
    w, h = int.from_bytes(data[16:20], "big"), int.from_bytes(data[20:24], "big")
    if not w or not h:
        raise ValueError("PNG with zero width or height")
    return w, h


def absolutize_images(text: str, base: Path) -> str:
    def rep(m: re.Match) -> str:
        src = m.group(2).strip()
        return m.group(0) if Path(src).is_absolute() else f"![{m.group(1)}]({(Path(base) / src).as_posix()})"
    return re.sub(r"(?m)^!\[([^\]]*)\]\(([^)]+)\)[ \t]*$", rep, text)


def load_template(path: Path) -> tuple[str, str]:
    """(styles.xml, page setup) of an institution template .docx; header/footer references are dropped."""
    if not Path(path).is_file():
        raise ValueError(f"template not found: {path}")
    try:
        with zipfile.ZipFile(path) as z:
            styles = z.read("word/styles.xml").decode("utf-8")
            doc = z.read("word/document.xml").decode("utf-8")
    except (zipfile.BadZipFile, KeyError) as e:
        raise ValueError(f"template {path} is not a usable .docx: {e}") from e
    sects = re.findall(r"<w:sectPr\b[^>]*>.*?</w:sectPr>", doc, re.S)
    if not sects:
        raise ValueError(f"template {path} has no page setup (w:sectPr) in word/document.xml")
    sect = re.sub(r"<w:(?:headerReference|footerReference|printerSettings)\b[^>]*/>", "", sects[-1])
    sect = re.sub(r'\s(?!w:)[A-Za-z][\w.-]*:[\w.-]+="[^"]*"', "", sect)  # attributes of undeclared namespaces
    return styles, sect


def _page(sect: str) -> tuple[int, int]:
    """Text-block width and height (twips) from a w:sectPr."""
    def attr(tag: str, name: str, default: int) -> int:
        m = re.search(rf'<w:{tag}\b[^>]*\bw:{name}="(\d+)"', sect)
        return int(m.group(1)) if m else default
    w, h = attr("pgSz", "w", A4[0]), attr("pgSz", "h", A4[1])
    return (w - attr("pgMar", "left", 1701) - attr("pgMar", "right", 1134),
            h - attr("pgMar", "top", 1134) - attr("pgMar", "bottom", 1134))


def _merge_styles(tpl: str, ours: str) -> str:
    have = set(re.findall(r'w:styleId="([^"]+)"', tpl))
    extra = [s for s in re.findall(r"<w:style\b.*?</w:style>", ours, re.S)
             if re.search(r'w:styleId="([^"]+)"', s).group(1) not in have]
    k = tpl.rfind("</w:styles>")
    if k < 0:
        raise ValueError("template styles.xml has no </w:styles>")
    return tpl[:k] + "".join(extra) + tpl[k:]


def _runs(text: str, bold_all: bool = False) -> str:
    """Runs for text; `code` spans lose their backticks and become monospace runs."""
    out = []
    for idx, part in enumerate(CODE.split(text)):
        if not part:
            continue
        if idx % 2 == 1:
            bold = "<w:b/>" if bold_all else ""
            out.append(f'<w:r><w:rPr><w:rFonts w:ascii="Consolas" w:hAnsi="Consolas" w:cs="Consolas"/>{bold}</w:rPr>'
                       f'<w:t xml:space="preserve">{html.escape(part)}</w:t></w:r>')
        else:
            out.append(_emph_runs(part, bold_all))
    return "".join(out)


def _emph_runs(text: str, bold_all: bool = False) -> str:
    out = []
    for idx, part in enumerate(INLINE.split(text.replace("\\*", ESC_STAR))):
        if not part:
            continue
        emph = idx % 2 == 1
        bold = bold_all or (emph and part.startswith("**"))
        italic = emph and not bold and part.startswith("*")
        body = part.strip("*") if emph else part
        props = ("<w:b/>" if bold else "") + ("<w:i/>" if italic else "")
        out.append(f'<w:r><w:rPr>{props}</w:rPr><w:t xml:space="preserve">'
                   f'{html.escape(body.replace(ESC_STAR, "*"))}</w:t></w:r>')
    return "".join(out)


def _p(text: str, style: str | None = None, indent: bool = False, quote: bool = False, num: int | None = None) -> str:
    ppr = f'<w:pStyle w:val="{style}"/>' if style else ""
    if num is not None:
        ppr += f'<w:numPr><w:ilvl w:val="0"/><w:numId w:val="{num}"/></w:numPr>'
    if indent:
        ppr += '<w:ind w:left="567" w:hanging="283"/>'
    if quote:
        ppr += '<w:ind w:left="567"/>'
    return f"<w:p><w:pPr>{ppr}</w:pPr>{_runs(text)}</w:p>"


def _table(rows: list[str]) -> str:
    cells = [[c.strip().replace(ESC_PIPE, "|") for c in r.strip().replace("\\|", ESC_PIPE).strip("|").split("|")]
             for r in rows]
    cells = [r for r in cells if not all(re.fullmatch(r":?-{3,}:?", c) for c in r)]
    ncol = max(len(r) for r in cells)
    width = 9000 // ncol
    border = "".join(f'<w:{s} w:val="single" w:sz="4" w:space="0" w:color="000000"/>'
                     for s in ("top", "left", "bottom", "right", "insideH", "insideV"))
    grid = "".join(f'<w:gridCol w:w="{width}"/>' for _ in range(ncol))
    trs = []
    for i, row in enumerate(cells):
        tcs = "".join(f'<w:tc><w:tcPr><w:tcW w:w="{width}" w:type="dxa"/></w:tcPr>'
                      f'<w:p>{_runs(c, bold_all=(i == 0))}</w:p></w:tc>' for c in row + [""] * (ncol - len(row)))
        trs.append(f"<w:tr>{tcs}</w:tr>")
    return (f'<w:tbl><w:tblPr><w:tblW w:w="{width * ncol}" w:type="dxa"/><w:tblBorders>{border}</w:tblBorders>'
            f"</w:tblPr><w:tblGrid>{grid}</w:tblGrid>{''.join(trs)}</w:tbl>")


def _toc() -> str:
    return ('<w:p><w:r><w:fldChar w:fldCharType="begin" w:dirty="true"/></w:r>'
            '<w:r><w:instrText xml:space="preserve"> TOC \\o "1-3" \\h \\z \\u </w:instrText></w:r>'
            '<w:r><w:fldChar w:fldCharType="separate"/></w:r>'
            '<w:r><w:t xml:space="preserve">Update field to build the table of contents / '
            'Cập nhật trường (Update field) để tạo mục lục</w:t></w:r>'
            '<w:r><w:fldChar w:fldCharType="end"/></w:r></w:p>')


def _drawing(n: int, cx: int, cy: int, name: str) -> str:
    return (f'<w:p><w:pPr><w:pStyle w:val="Figure"/></w:pPr><w:r><w:drawing>'
            f'<wp:inline distT="0" distB="0" distL="0" distR="0"><wp:extent cx="{cx}" cy="{cy}"/>'
            f'<wp:docPr id="{n}" name="Picture {n}" descr="{html.escape(name, quote=True)}"/>'
            '<wp:cNvGraphicFramePr><a:graphicFrameLocks noChangeAspect="1"/></wp:cNvGraphicFramePr>'
            '<a:graphic><a:graphicData uri="http://schemas.openxmlformats.org/drawingml/2006/picture">'
            f'<pic:pic><pic:nvPicPr><pic:cNvPr id="{n}" name="image{n}.png"/><pic:cNvPicPr/></pic:nvPicPr>'
            f'<pic:blipFill><a:blip r:embed="rIdImg{n}"/><a:stretch><a:fillRect/></a:stretch></pic:blipFill>'
            f'<pic:spPr><a:xfrm><a:off x="0" y="0"/><a:ext cx="{cx}" cy="{cy}"/></a:xfrm>'
            '<a:prstGeom prst="rect"><a:avLst/></a:prstGeom></pic:spPr></pic:pic>'
            '</a:graphicData></a:graphic></wp:inline></w:drawing></w:r></w:p>')


def _image(src: str, ctx: _Ctx) -> str:
    path = Path(src.strip())
    if not path.is_absolute():
        path = ctx.base_dir / path
    if not path.is_file():
        raise ValueError(f"image not found: {src.strip()}")
    data = path.read_bytes()
    w, h = png_size(data)
    cx = ctx.text_w * EMU_PER_TWIP
    cy = cx * h // w
    max_cy = ctx.text_h * EMU_PER_TWIP * 9 // 10
    if cy > max_cy:
        cx, cy = cx * max_cy // cy, max_cy
    ctx.images.append(data)
    return _drawing(len(ctx.images), cx, cy, path.name)


def _body(md_text: str, ctx: _Ctx | None = None) -> str:
    ctx = ctx or _Ctx(None, *_page(""))
    lines = [COMMENT.sub("", ln).rstrip() for ln in CTRL.sub("", md_text).splitlines()]
    out, i, after_table, prev_numbered = [], 0, False, False
    while i < len(lines):
        ln = lines[i]
        if ln.startswith("|"):
            rows = []
            while i < len(lines) and lines[i].startswith("|"):
                rows.append(lines[i])
                i += 1
            out.append(_table(rows))
            after_table, prev_numbered = True, False
            continue
        nxt = lines[i + 1] if i + 1 < len(lines) else ""
        numbered = False
        if not ln.strip():
            after_table = False
        elif ln.strip() == "\\newpage":
            out.append('<w:p><w:r><w:br w:type="page"/></w:r></w:p>')
        elif ln.strip() == "{TOC}":
            out.append(_toc())
            ctx.toc = True
        elif m := re.match(r"^(#{1,4})\s+(.*)", ln):
            out.append(_p(m.group(2), f"Heading{len(m.group(1))}"))
        elif m := IMAGE.match(ln.strip()):
            out.append(_image(m.group(2), ctx))
            if m.group(1).strip():
                out.append(_p(m.group(1).strip(), "FigureCaption"))
        elif CAPTION.match(ln) and nxt.startswith("|"):
            out.append(_p(ln, "Caption"))
        elif after_table and NOTE.match(ln):
            out.append(_p(ln, "TableNote"))
        elif QUOTE.match(ln):
            out.append(_p(QUOTE.match(ln).group(1), quote=True))
        elif BULLET.match(ln):
            out.append(_p(BULLET.sub("", ln), "ListParagraph", num=1))
        elif m := NUMBERED.match(ln):
            if not prev_numbered:
                ctx.num_starts.append(int(m.group(1)))
            out.append(_p(ln[m.end():], "ListParagraph", num=len(ctx.num_starts) + 1))
            numbered = True
        else:
            out.append(_p(ln))
        prev_numbered = numbered
        i += 1
    return "".join(out)


def _numbering(starts: list[int]) -> str:
    def abstract(aid: int, fmt: str, text: str) -> str:

    nums = '<w:num w:numId="1"><w:abstractNumId w:val="0"/></w:num>'
    for k, start in enumerate(starts):

                 f'<w:lvlOverride w:ilvl="0"><w:startOverride w:val="{start}"/></w:lvlOverride></w:num>')
    return f"{XML_HEAD}<w:numbering {W}>" + abstract(0, "bullet", "–") + abstract(1, "decimal", "%1.") + nums + "</w:numbering>"

    sect = re.sub(r"^<w:sectPr\b([^>]*)>",
                  lambda m: f'<w:sectPr{m.group(1)}><w:footerReference w:type="default" r:id="rId3"/>', sect, count=1)

                         for n in range(1, len(ctx.images) + 1))
````

```python
class Refused(Exception):
    """A gate that cannot be opened yet (CLI: exit 1, reason on stdout)."""


def waived(project: Path, gate: str) -> bool:
    return _waived(project, gate)


def audit_status(project: Path) -> tuple[dict | None, list[str]]:
    p = Path(project) / AUDIT
    if not p.is_file():
        return None, ["reviews/audit.json not found: run /orchestra:audit (audit.py) first"]
    try:
        data = json.loads(p.read_text(encoding="utf-8"))
    except (ValueError, OSError) as e:
        return None, [f"reviews/audit.json is unreadable: {e}"]
    if not isinstance(data, dict) or not isinstance(data.get("files"), dict) \
            or not isinstance(data.get("blocks"), int) or isinstance(data.get("blocks"), bool):
        return None, ["reviews/audit.json lacks 'blocks' or 'files'"]
    why = []
    if data["blocks"]:
        why.append(f"the audit has {data['blocks']} blocking finding(s); see reviews/audit.md")
    if not data["files"]:
        why.append("reviews/audit.json lists no files")
    root = Path(project).resolve()
    for rel, digest in sorted(data["files"].items()):
        f = Path(project) / rel
        if Path(rel).is_absolute() or not f.resolve().is_relative_to(root):
            why.append(f"{rel} is outside the project")
        elif not f.is_file():
            why.append(f"{rel} is missing since the audit")
        elif sha256(f) != digest:
            why.append(f"{rel} changed since the audit")
    return data, why

    ds = data.get("deliverables")
```

```python
#!/usr/bin/env python3
"""orchestra gate hook (PreToolUse on Bash|PowerShell|Agent|Task); reads the hook JSON on stdin.

- A shell command running `assemble.py <project> <deliverable> … --final`, or `build_docx.py … <dir>/out/thesis.docx`
  (or manuscript.docx), is denied unless `gate.py check <project> G4` passes for that deliverable. The project is
  the <project> argument (build_docx: --project, else the folder holding out/), else the working directory.
- An Agent/Task prompt containing `orchestra-role:` is denied unless G3 is open for the project in the working
  directory (the nearest folder upward with project.yaml).
- Anything else, or no project.yaml: allowed silently (no output). The hook never blocks on its own errors: it
  answers "ask" with the error text. Exit code always 0. Standard library only.
"""
from __future__ import annotations

import json
import re
import shlex
import sys
from pathlib import Path

for _s in (sys.stdout, sys.stderr):
    try:
        _s.reconfigure(encoding="utf-8", errors="replace")
    except Exception:  # noqa: BLE001
        pass

sys.path.insert(0, str(Path(__file__).resolve().parent))
import gate  # noqa: E402

SHELL = ("Bash", "PowerShell")
AGENT = ("Agent", "Task")
ROLE = re.compile(r"orchestra-role:\s*([\w-]+)")
SEP = re.compile(r"&&|\|\||[;|\n]")
CD = {"cd", "set-location", "sl", "pushd", "chdir"}
OPTS_WITH_VALUE = {"assemble.py": {"--lang"}, "build_docx.py": {"--project", "--template"}}
FINAL_NAMES = ("thesis.docx", "manuscript.docx")


def _tokens(segment: str) -> list[str]:
    try:
        toks = shlex.split(segment, posix=False)
    except ValueError:
        toks = segment.split()
    return [t.strip("\"'") for t in toks]


def _name(tok: str) -> str:
    return tok.replace("\\", "/").rsplit("/", 1)[-1].lower()


def _args(toks: list[str], i: int, script: str) -> tuple[list[str], dict]:
    pos, opts, k = [], {}, i + 1
    while k < len(toks):
        t = toks[k]
        if t.startswith("-"):
            key, eq, val = t.partition("=")
            if key in OPTS_WITH_VALUE[script] and not eq:
                opts[key] = toks[k + 1] if k + 1 < len(toks) else ""
                k += 2
                continue
            opts[key] = val if eq else True
        else:
            pos.append(t)
        k += 1
    return pos, opts


def exports(command: str, cwd: Path) -> list[tuple[Path, str, str]]:
    """(project, deliverable, what) for every final export the command would run."""
    found = []
    for seg in SEP.split(command):
        toks = _tokens(seg.strip())
        if not toks:
            continue
        if toks[0].lower() in CD:
            target = next((t for t in toks[1:] if not t.startswith("-")), None)
            if target:
                cwd = cwd / target
            continue
        for i, tok in enumerate(toks):
            name = _name(tok)
            if name == "assemble.py":
                pos, opts = _args(toks, i, name)
                if "--final" in opts:
                    found.append((cwd / pos[0] if pos else cwd, pos[1] if len(pos) > 1 else "", "assemble.py --final"))
            elif name == "build_docx.py":
                pos, opts = _args(toks, i, name)
                if len(pos) >= 2:
                    out = cwd / pos[-1]
                    if out.name.lower() in FINAL_NAMES and out.parent.name.lower() == "out":
                        proj = opts.get("--project")
                        project = cwd / proj if isinstance(proj, str) and proj else out.parent.parent
                        found.append((project, out.stem.lower(), f"build_docx.py → out/{out.name}"))
    return found


def _find_project(start: Path) -> Path | None:
    start = start.resolve()
    for p in (start, *start.parents):
        if (p / "project.yaml").is_file():
            return p
    return None


def _deny(reason: str) -> dict:
    return {"permissionDecision": "deny", "permissionDecisionReason": reason}


def decide(data: dict) -> dict | None:
    tool = str(data.get("tool_name", ""))
    tin = data.get("tool_input") or {}
    cwd = Path(str(data.get("cwd") or ".")).expanduser()
    if tool in SHELL:
        cmd = str(tin.get("command", "")) if isinstance(tin, dict) else str(tin)
        if "assemble.py" not in cmd and "build_docx.py" not in cmd:
            return None
        for project, deliverable, what in exports(cmd, cwd):
            if not (project / "project.yaml").is_file():
                continue
            ok, why = gate.check_gate(project, "G4", deliverable or None)
            if not ok:
                scope = f" for the {deliverable}" if deliverable else ""
                return _deny(f"[orchestra] {what} is a final export and G4 is not open{scope}: {'; '.join(why)}. "
                             "Run /orchestra:audit, fix every block, then the author opens G4 "
                             "(gate.py open . G4 --by NAME) and the export runs again. / "
                             "Xuất bản cuối cần cổng G4 mở: chạy /orchestra:audit, sửa hết lỗi chặn, rồi tác giả mở G4.")
        return None
    if tool in AGENT:
        text = " ".join(str(tin.get(k, "")) for k in ("prompt", "description")) if isinstance(tin, dict) else str(tin)
        m = ROLE.search(text)
        if not m:
            return None
        project = _find_project(cwd)
        if project is None:
            return None
        ok, why = gate.check_gate(project, "G3")
        if not ok:
            return _deny(f"[orchestra] writer role '{m.group(1)}' needs locked results and G3 is not open: "
                         f"{'; '.join(why)}. The author reviews the results and locks them first "
                         "(gate.py lock . G3 --by NAME --files …). / "
                         "Vai trò viết cần kết quả đã được tác giả khoá (G3); hãy khoá kết quả trước.")
    return None


def main() -> int:
    try:
        data = json.loads(sys.stdin.buffer.read().decode("utf-8-sig", errors="replace") or "{}")
        if not isinstance(data, dict):
            raise ValueError("input is not a JSON object")
        d = decide(data)
    except Exception as e:  # noqa: BLE001 - never block on our own errors
        d = {"permissionDecision": "ask", "permissionDecisionReason": (
            f"[orchestra] gate hook error ({type(e).__name__}: {e}); review this call before allowing. / "
            "Lỗi hook kiểm tra cổng; hãy xem lại trước khi cho phép.")}
    if d:
        print(json.dumps({"hookSpecificOutput": {"hookEventName": "PreToolUse", **d}}, ensure_ascii=False))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
    chunk = "\n".join(lines[max(0, line - 1 - WINDOW):min(len(lines), line + WINDOW)])
    return [chunk, render_results.render_text(chunk, by_id, lang)[0]] if by_id else [chunk]


def check(project: Path, guideline: str | None = None, checklist_path: Path | None = None) -> list[tuple[str, str, str]]:
    project = Path(project)
    code = guideline_code(project, guideline)
    items = load_items(code)
    data, text = load_checklist(project, checklist_path)
    entries, found = data["items"], []
    if str(data.get("guideline", "")).upper() != code.upper():
        found.append(("block", f"{CHECKLIST}:1", f"the checklist is for {data.get('guideline')!r}; the project uses {code}"))
    by_id, lang = _ledger(project), projectcfg.output_lang(project)
    ids = [it["id"] for it in items["items"]]
    section = {it["id"]: it["section"] for it in items["items"]}
    for iid in ids:
        e, loc = entries.get(iid), f"{CHECKLIST}:{_json_line(text, iid)}"
        if not isinstance(e, dict):
            found.append(("block", f"{CHECKLIST}:1", f"item {iid} ({section[iid]}) is missing from the checklist"))
            continue
        st = e.get("status")
        rel, line, quote = e.get("file"), e.get("line"), str(e.get("quote") or "")
        has_loc = isinstance(rel, str) and rel and isinstance(line, int) and not isinstance(line, bool) and line >= 1
        if st not in STATUSES:
            found.append(("block", loc, f"item {iid}: unknown status {st!r} (present, partial, absent, na)"))
        elif st == "absent":
            found.append(("block", loc, f"item {iid} ({section[iid]}) is absent: add it to the draft or record why it does not apply"))
        elif st == "na":
            if not str(e.get("reason") or "").strip():
                found.append(("block", loc, f"item {iid} is marked NA without a reason"))
        elif st == "partial":
            found.append(("warn", f"{rel}:{line}" if has_loc else loc,
                          f"item {iid} is only partly reported: {e.get('reason') or 'see the checklist'}"))
        elif not has_loc or not quote.strip():
            found.append(("block", loc, f"item {iid} is present but has no file, line or quote"))
        else:
            wins = _windows(project, rel, line, by_id, lang)
            if wins is None:
                found.append(("block", loc, f"item {iid}: {rel} not found"))
            elif not any(_norm(quote) in _norm(w) for w in wins):
                found.append(("block", f"{rel}:{line}",
                              f"item {iid} is present, but its quote is not within ±{WINDOW} lines of {rel}:{line}"))
    for extra in sorted(set(entries) - set(ids)):
        found.append(("warn", f"{CHECKLIST}:{_json_line(text, extra)}", f"item {extra} is not an item of {code}"))
    return found

    project = Path(project)
    code = guideline_code(project, guideline)
    items = load_items(code)["items"]
    entries = load_checklist(project, checklist_path)[0]["items"]
    vi = projectcfg.output_lang(project) == "vi"
    head = ("| Mục | Phần | Nội dung (diễn giải) | Trạng thái | Vị trí |" if vi
            else "| Item | Section | Recommendation (paraphrase) | Status | Location |")
    rows = [head, "|---|---|---|---|---|"]
    for it in items:
        e = entries.get(it["id"]) if isinstance(entries.get(it["id"]), dict) else {}
        st = e.get("status", "absent")
        where = e.get("reason", "") if st == "na" else (f"{e.get('file')}:{e.get('line')}" if e.get("file") else "")
        label = STATUS_VI.get(st, st) if vi else ("NA" if st == "na" else st)
        rows.append(f"| {it['id']} | {it['section']} | {it['text']} | {label} | {str(where).replace('|', '/')} |")
    return "\n".join(rows) + "\n"
```

```python
        if not hits:

    return h.hexdigest()
```

import json
import re

REVIEWERS = {
    "citation-verifier": ("reviews/citation-verifier.md", ("citations",)),
    "statistical-reviewer": ("reviews/statistical-reviewer.md", ("statistics",)),
    "reporting-guideline-checker": ("reviews/reporting-guideline-checker.md", ("guideline",)),
    "scientific-editor": ("reviews/scientific-editor.md", ("structure", "claim_scope", "limitations")),
    "consistency-auditor": ("reviews/consistency.md", ("consistency",)),
}

SCORES = re.compile(r"^```scores[ \t]*\r?\n(.*?)\r?\n```[ \t]*$", re.M | re.S)
DIGEST = re.compile(r"^drafts-digest:[ \t]*(thesis|manuscript)[ \t]+([0-9a-f]{64})[ \t]*$", re.M)
REQUEST = re.compile(r"^[ \t]*(?:[-*][ \t]*)?NEW-ANALYSIS:[ \t]*(\S.*?)[ \t]*$", re.M)
NONE = {"none", "không có", "không", "n/a", "-"}


def parse_report(text: str) -> dict:
    blocks, bad = [], 0
    for m in SCORES.finditer(text):
        try:
            obj = json.loads(m.group(1))
        except ValueError:
            bad += 1
            continue
        if isinstance(obj, dict):
            blocks.append(obj)
        else:
            bad += 1
    return {"scores": blocks, "bad_scores": bad, "digests": dict(DIGEST.findall(text)),
            "requests": [r for r in REQUEST.findall(text) if r.strip("() .").lower() not in NONE]}


def scores_for(parsed: dict, deliverable: str) -> dict | None:
    return next((s for s in parsed["scores"] if s.get("deliverable") == deliverable), None)

def _decide(scores: dict, total: int, rnd: int, kept: dict | None) -> str:
    if kept is not None:
        loss = [c for c in reviews.CRITERIA if scores[c] < kept["scores"].get(c, 0)]
        if total < kept["total"] or (total == kept["total"] and loss):
            return "REVERT"
        if total == kept["total"]:
            return "STOP"
    if total == MAX_TOTAL or rnd >= MAX_ROUNDS:
        return "STOP"
    return "KEEP"

def score(project: Path, deliverable: str, rnd: int) -> dict:
    project = Path(project)
    log = load_log(project)
    mine = [e for e in log["rounds"] if e.get("deliverable") == deliverable]
    last = max((e["round"] for e in mine), default=0)
    if mine and mine[-1].get("decision") in ("REVERT", "STOP"):
        raise UsageError(f"the {deliverable} loop stopped at round {last} ({mine[-1]['decision']}); no further rounds")
    if rnd != last + 1:
        raise UsageError(f"--round must be {last + 1} for the {deliverable}")
    if rnd > MAX_ROUNDS:
        raise UsageError(f"at most {MAX_ROUNDS} rounds")
    if not drafts.draft_files(project, deliverable):
        raise UsageError(f"no drafts in 06_writing/{deliverable}/")
    current = drafts.digest(project, deliverable)
    scores: dict = {}
    said: dict = {}
    notes: list = []
    requests: list = []
    for agent, (rel, crits) in reviews.REVIEWERS.items():
        path = project / rel
        if not path.is_file():
            raise UsageError(f"{rel} not found: run the {agent} agent on the {deliverable} first")
        parsed = reviews.parse_report(path.read_text(encoding="utf-8-sig"))
        block = reviews.scores_for(parsed, deliverable)
        if block is None:
            raise UsageError(f"{rel} has no ```scores block for the {deliverable}")
        if parsed["digests"].get(deliverable) != current:
            raise UsageError(f"{rel}: its drafts-digest does not match the current {deliverable} drafts; rerun {agent}")
        for c in crits:
            v = block.get(c)
            if c in SCRIPTED:
                if v is not None:
                    said[c] = v
                continue
            if isinstance(v, bool) or v not in (0, 1, 2):
                raise UsageError(f"{rel}: '{c}' must be 0, 1 or 2 (got {v!r})")
            scores[c] = v
        requests += [{"agent": agent, "text": t} for t in parsed["requests"]]
    for key, (val, why) in (("guideline", guideline_score(project)), ("consistency", consistency_score(project)),
                            ("prose", prose_score(project, deliverable))):
        scores[key] = val
        notes.append(f"{key} {val}: {why}")
        if key in said and said[key] != val:
            notes.append(f"{key}: the reviewer gave {said[key]}, the script measured {val}; the script value is used")
    total = sum(scores[c] for c in reviews.CRITERIA)
    kept = next((e for e in reversed(mine) if e.get("kept")), None)
    decision = _decide(scores, total, rnd, kept)
    prev = round_dir(project, deliverable, last) if last else None
    snap = snapshot(project, deliverable, rnd)
    entry = {"deliverable": deliverable, "round": rnd, "at": _now(),
             "scores": {c: scores[c] for c in reviews.CRITERIA}, "total": total, "max": MAX_TOTAL,
             "decision": decision, "kept": decision != "REVERT",
             "compared_with": kept["round"] if kept else None, "compared_total": kept["total"] if kept else None,
             "drafts_digest": current, "files_changed": _changed(snap, prev), "requests": requests, "notes": notes}
    log["rounds"].append(entry)
    save_log(project, log)
    return entry


def revert(project: Path, deliverable: str, to: int | None = None) -> dict:
    project = Path(project)
    log = load_log(project)
    mine = [e for e in log["rounds"] if e.get("deliverable") == deliverable]
    if to is None:
        kept = [e for e in mine if e.get("kept")]
        if not kept:
            raise UsageError(f"no kept round of the {deliverable} to revert to")
        to = kept[-1]["round"]
    snap = round_dir(project, deliverable, to)
    if not snap.is_dir():
        raise UsageError(f"snapshot reviews/rounds/{deliverable}/r{to} not found")
    base = drafts.folder(project, deliverable)
    want = sorted(p.name for p in snap.iterdir() if p.is_file())
    removed = []
    for p in drafts.tracked_files(project, deliverable):
        if p.name not in want:
            p.unlink()
            removed.append(p.name)
    for name in want:
        shutil.copyfile(snap / name, base / name)

             "restored": want, "removed": removed}

    save_log(project, log)
    return event


def assumptions(project: Path) -> list[tuple[str, str]]:
    out: list[tuple[str, str]] = []
    for rel in SOURCES:
        p = Path(project) / rel
        if not p.is_file():
            continue
        lines = p.read_text(encoding="utf-8-sig").splitlines()
        i = 0
        while i < len(lines):
            if not HEAD.search(lines[i]):
                i += 1
                continue
            j, skipped = i + 1, 0
            while j < len(lines) and lines[j].strip() and not BULLET.match(lines[j]) and skipped < 3:
                j, skipped = j + 1, skipped + 1
            while j < len(lines) and lines[j].strip():
                m = BULLET.match(lines[j])
                if m:
                    out.append((f"{rel}:{j + 1}", m.group(1).strip()))
                elif out and lines[j][:1] in (" ", "\t"):
                    out[-1] = (out[-1][0], out[-1][1] + " " + lines[j].strip())
                else:
                    break
                j += 1
            i = j
    return out

    return [(f"decisions.md:{n}", m.group(1)) for n, ln in enumerate(p.read_text(encoding="utf-8-sig").splitlines(), 1)

def decisions_text(project: Path, log: dict) -> str:
    t = TEXT["vi" if projectcfg.output_lang(project) == "vi" else "en"]
    lines = [t["title"], "", t["note"], "", t["req"], ""]
    seen, reqs = set(), []
    for e in log["rounds"]:
        for r in e.get("requests", []):
            key = (e["deliverable"], r["text"])
            if key not in seen:
                seen.add(key)
                reqs.append(f"- [{t[e['deliverable']]}, {t['round']} {e['round']}, {r['agent']}] {r['text']} — {t['ask']}")
    lines += reqs or [t["none"]]
    lines += ["", t["ass"], ""]
    lines += [f"- {text} (`{loc}`)" for loc, text in assumptions(project)] or [t["none"]]
    lines += ["", t["waive"], ""]
    lines += [f"- `{text}` (`{loc}`)" for loc, text in waivers(project)] or [t["none"]]
    return "\n".join(lines) + "\n"


def write_decisions(project: Path) -> tuple[int, Path]:

        _write(alt, text)
        return 1, alt
    _write(out, text)

    save_log(project, log)
    return 0, out

```python
#!/usr/bin/env python3
"""Assemble a thesis or manuscript from its section drafts and build the .docx.

  python assemble.py <project> thesis|manuscript [--final] [--lang vi|en]

Order: 06_writing/<deliverable>/order.txt (one file name or glob per line, # comments) or the default (thesis:
00-tom-tat, 00-dat-van-de, ch1-*, ch2-methods, ch3-results, ch4-discussion, 05-ket-luan, 06-kien-nghi, 90-phu-luc;
manuscript: 00-title, 01-abstract, 02-introduction, 03-methods, 04-results, 05-discussion, 06-conclusion). A
missing optional file is a warning; a missing required section (Chương 2/3/4 and Kết luận; Introduction,
Methods, Results, Discussion) is E-FMT block. {{R-…}} placeholders are rendered from the results ledger (E-NUM
block when one cannot be); per-section {REFERENCES} lines (and the heading right above) are dropped and the
citations are numbered once over the whole text (cite_render; E-REF block for an id not in references.json or
retracted), with the list under "TÀI LIỆU THAM KHẢO" / "References" (a thesis: before the appendix). Captions are
checked (E-FMT): "Bảng c.n" / "Hình c.n" / "Biểu đồ c.n" per thesis chapter, "Table n" / "Figure n" (or Bảng n /
Hình n) across a manuscript; numbers start at 1 without gaps or duplicates and every mention has a caption; a
line with <!-- fmt-ok: reason --> is skipped. Images must exist and be PNG.
Writes 06_writing/<d>/<d>.assembled.md and <d>.draft.docx (draft notice first). --final needs gate G4 open for the
deliverable and reviews/audit.json still matching (gate.py), then writes out/<d>.docx without the notice.
Exit codes: 0 = written; 1 = blocking findings or --final refused (nothing written); 2 = usage, I/O or missing input.
"""
from __future__ import annotations

import argparse
import json
import re
import sys
import zipfile
from pathlib import Path

for _s in (sys.stdout, sys.stderr):
    try:
        _s.reconfigure(encoding="utf-8", errors="replace")
    except Exception:  # noqa: BLE001
        pass

sys.path.insert(0, str(Path(__file__).resolve().parent))
from crolib import drafts, ledgers  # noqa: E402
import build_docx  # noqa: E402
import cite_render  # noqa: E402
import gate  # noqa: E402
import render_results  # noqa: E402

KIND = {"Bảng": "table", "Table": "table", "Hình": "figure", "Figure": "figure", "Biểu đồ": "chart"}
CAP = re.compile(r"^(?:!\[)?(Bảng|Table|Hình|Biểu đồ|Figure)\s+(\d+(?:\.\d+)?)(?:\s*\([^)]*\))?\.(?:\s|$)")
MENTION = re.compile(r"(?<!\w)(Bảng|Table|Hình|Biểu đồ|Figure)\s+(\d+(?:\.\d+)?)")
CHAPTER_FILE = re.compile(r"^ch(\d+)-")
CHAPTER_HEAD = re.compile(r"(?im)^#\s+(?:chương|chapter)\s+(\d+)\b")
IMAGE = re.compile(r"^!\[([^\]]*)\]\(([^)]+)\)\s*$")
COMMENT = re.compile(r"<!--.*?-->", re.S)
REF_HEAD = re.compile(r"^#{1,4}\s*(?:tài liệu tham khảo|references?)\s*$", re.I)
AUTHOR_TODO = re.compile(r"\[\[(?:AUTHOR|TÁC GIẢ)\s*:[^\]]*\]\]")
NOTICE = {"vi": "**BẢN NHÁP – chưa xuất qua cổng G4; không nộp bản này.**",
          "en": "**DRAFT – not released through gate G4; do not submit this version.**"}
REF_TITLE = {"vi": "TÀI LIỆU THAM KHẢO", "en": "References"}
TOC_TITLE = {"vi": "**MỤC LỤC**", "en": "**CONTENTS**"}


def _mask(text: str) -> str:
    return COMMENT.sub(lambda m: re.sub(r"[^\n]", " ", m.group(0)), text)


def chapter_of(name: str, text: str) -> int | None:
    m = CHAPTER_FILE.match(name) or CHAPTER_HEAD.search(text)
    return int(m.group(1)) if m else None


def caption_findings(sections: list[tuple[str, str]], deliverable: str) -> list[tuple[str, str, str, str]]:
    found: list = []
    seen: dict = {}
    last: dict = {}
    masked = [(rel, text, _mask(text)) for rel, text in sections]
    for rel, text, mtext in masked:
        name = rel.rsplit("/", 1)[-1]
        chap = chapter_of(name, text) if deliverable == "thesis" else None
        appendix = deliverable == "thesis" and name[:1] == "9"
        for i, (line, mline) in enumerate(zip(text.splitlines(), mtext.splitlines()), 1):
            if "fmt-ok" in line:
                continue
            m = CAP.match(mline.strip())
            if not m:
                continue
            word, num = m.group(1), m.group(2)
            kind, loc, parts = KIND[word], f"{rel}:{i}", num.split(".")
            if appendix:
                seen.setdefault((kind, num), loc)
                continue
            if deliverable == "thesis":
                if chap is None:
                    found.append(("E-FMT", "warn", loc, f"{word} {num} is outside a numbered chapter"))
                    seen.setdefault((kind, num), loc)
                    continue
                if len(parts) != 2 or int(parts[0]) != chap:
                    found.append(("E-FMT", "block", loc, f"{word} {num} in chapter {chap} must be numbered {word} {chap}.n"))
                    continue
                scope, n = chap, int(parts[1])
            else:
                if len(parts) != 1:
                    found.append(("E-FMT", "block", loc, f"{word} {num}: a manuscript numbers {word} 1, 2, 3 … across the paper"))
                    continue
                scope, n = 0, int(parts[0])
            if (kind, num) in seen:
                found.append(("E-FMT", "block", loc, f"{word} {num} is used twice (first at {seen[(kind, num)]})"))
                continue
            seen[(kind, num)] = loc
            expected = last.get((scope, kind), 0) + 1
            if n != expected:
                want = f"{scope}.{expected}" if deliverable == "thesis" else str(expected)
                found.append(("E-FMT", "block", loc,
                              f"{word} {num} out of sequence: expected {word} {want} (numbers start at 1, no gaps)"))
            last[(scope, kind)] = max(n, last.get((scope, kind), 0))
    for rel, text, mtext in masked:
        for i, (line, mline) in enumerate(zip(text.splitlines(), mtext.splitlines()), 1):
            if "fmt-ok" in line:
                continue
            cap = CAP.match(mline.strip())
            rest = mline.strip()[cap.end():] if cap else mline
            for m in MENTION.finditer(rest):
                if (KIND[m.group(1)], m.group(2)) not in seen:
                    found.append(("E-FMT", "block", f"{rel}:{i}",
                                  f"{m.group(1)} {m.group(2)} is mentioned but no caption has that number"))
    return found


def image_findings(base: Path, sections: list[tuple[str, str]]) -> list[tuple[str, str, str, str]]:
    found = []
    for rel, text in sections:
        for i, line in enumerate(text.splitlines(), 1):
            m = IMAGE.match(line.strip())
            if not m:
                continue
            src = m.group(2).strip()
            p = Path(src) if Path(src).is_absolute() else Path(base) / src
            if not p.is_file():
                found.append(("E-FMT", "block", f"{rel}:{i}", f"image not found: {src}"))
                continue
            try:
                build_docx.png_size(p.read_bytes()[:32])
            except ValueError:
                found.append(("E-FMT", "block", f"{rel}:{i}", f"only PNG images are supported: {src}"))
    return found


def format_findings(project: Path, deliverable: str, strict: bool = False) -> list[tuple[str, str, str, str]]:
    project = Path(project)
    files, missing, required = drafts.ordered(project, deliverable)
    base_rel = f"06_writing/{deliverable}"

             for n in required]
    found += [("E-FMT", "warn", f"{base_rel}/{e}:1", "in the section order but not found; skipped")
              for e in missing if e not in drafts.REQUIRED[deliverable]]
    listed = {p.name for p in files}
    found += [("E-FMT", "warn", f"{base_rel}/{p.name}:1", "draft not in the section order; not assembled")

def _drop_reference_lists(text: str) -> str:
    lines = text.split("\n")
    for i, ln in enumerate(lines):
        if ln.strip() == "{REFERENCES}":
            lines[i] = ""
            j = i - 1
            while j >= 0 and not lines[j].strip():
                j -= 1
            if j >= 0 and REF_HEAD.match(lines[j].strip()):
                lines[j] = ""
    return "\n".join(lines)


def _results(project: Path) -> dict:
    p = Path(project) / "ledgers" / "results-ledger.json"
    if not p.is_file():
        return {}
    data = json.loads(p.read_text(encoding="utf-8-sig"))
    recs = data.get("results") if isinstance(data, dict) else None
    if not isinstance(recs, list):
        raise ValueError("results ledger must be an object with a 'results' list")
    return {r.get("id"): r for r in recs if isinstance(r, dict)}


def _join(parts: list[tuple[str, str]], deliverable: str, lang: str) -> str:
    ref_block = f"# {REF_TITLE[lang]}\n\n{{REFERENCES}}"
    chunks: list[tuple[str, bool]] = []
    if deliverable == "thesis" and not any(ln.strip() == "{TOC}" for _, t in parts for ln in t.splitlines()):
        chunks.append((f"{TOC_TITLE[lang]}\n\n{{TOC}}", False))
    placed = not any(cite_render.cited_ids(t) for _, t in parts)
    prev = None
    for name, t in parts:
        if deliverable == "thesis" and name.startswith("9") and not placed:
            chunks.append((ref_block, True))
            placed = True
        brk = bool(chunks) and (deliverable == "thesis" or prev in ("00-title.md", "01-abstract.md"))
        chunks.append((t, brk))
        prev = name
    if not placed:
        chunks.append((ref_block, True))
    out: list[str] = []
    for t, brk in chunks:
        if out:
            out.append("\n\n\\newpage\n\n" if brk else "\n\n")
        out.append(t)
    return "".join(out) + "\n"


def build_text(project: Path, deliverable: str, lang: str) -> tuple[str, list, dict]:
    project = Path(project)
    findings = format_findings(project, deliverable)
    files, _, _ = drafts.ordered(project, deliverable)
    by_res = _results(project)
    refs = {r.get("id"): r for r in ledgers.load_references(project / "ledgers" / "references.json") if isinstance(r, dict)}
    parts = []
    for p in files:
        rel = f"06_writing/{deliverable}/{p.name}"
        raw = p.read_text(encoding="utf-8-sig")
        rendered, probs = render_results.render_text(_drop_reference_lists(raw), by_res, lang)
        for x in probs:
            line, _, msg = x.partition(": ")
            findings.append(("E-NUM", "block", f"{rel}:{line}", msg))
        for i, line in enumerate(_mask(raw).splitlines(), 1):
            for k in cite_render.cited_ids(line):
                if k not in refs:
                    findings.append(("E-REF", "block", f"{rel}:{i}", f"[@{k}] is not in ledgers/references.json"))
                elif refs[k].get("retracted"):
                    findings.append(("E-REF", "block", f"{rel}:{i}", f"[@{k}] is retracted"))
        parts.append((p.name, rendered.strip("\n")))
    stats = {"sections": len(parts), "references": 0}
    if any(f[1] == "block" for f in findings):
        return "", findings, stats
    text, order = cite_render.render(_join(parts, deliverable, lang), refs)
    stats["references"] = len(order)
    return text, findings, stats


def final_problems(project: Path, deliverable: str) -> list[str]:
    ok, why = gate.check_gate(project, "G4", deliverable)
    problems = [] if ok else list(why)
    data, stale = gate.audit_status(project)
    if gate.waived(project, "G4"):

    problems += [w for w in stale if w not in problems]
    if data is not None and deliverable not in gate.audited_deliverables(data):
        problems.append(f"reviews/audit.json is not an audit of the {deliverable}")
    return problems


def _write_text(path: Path, text: str) -> None:
    with open(path, "w", encoding="utf-8", newline="\n") as fh:
        fh.write(text)


def assemble(project: Path, deliverable: str, final: bool = False, lang: str | None = None) -> int:
    project = Path(project)
    lang = lang or drafts.lang_of(project, deliverable)
    if final:
        problems = final_problems(project, deliverable)
        if problems:
            print(f"assemble: G4: closed for the {deliverable} — " + "; ".join(problems))
            print("assemble: nothing written; run audit.py, fix every block, then the author opens G4")
            return 1
    text, findings, stats = build_text(project, deliverable, lang)
    for code, level, loc, msg in findings:
        print(f"{code} {level} {loc}: {msg}")
    blocks = sum(1 for f in findings if f[1] == "block")
    print(f"assemble: {deliverable}: {stats['sections']} sections, {stats['references']} references, "
          f"{blocks} block, {len(findings) - blocks} warn")
    if blocks:
        print("assemble: nothing written")
        return 1
    base = drafts.folder(project, deliverable)
    md = base / f"{deliverable}.assembled.md"
    _write_text(md, text)
    settings, template = build_docx.settings_from_project(project), build_docx.template_from_project(project)
    if final:
        dest = project / "out" / f"{deliverable}.docx"
        dest.parent.mkdir(parents=True, exist_ok=True)
        dest.write_bytes(build_docx.build(text, settings, base_dir=base, template=template))
    else:
        dest = base / f"{deliverable}.draft.docx"
        dest.write_bytes(build_docx.build(NOTICE[lang] + "\n\n" + text, settings, base_dir=base, template=template))
    print(f"assemble: wrote {md.relative_to(project).as_posix()}")
    print(f"assemble: wrote {dest.relative_to(project).as_posix()}")
    return 0


def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("project")
    ap.add_argument("deliverable", choices=drafts.DELIVERABLES)
    ap.add_argument("--final", action="store_true")
    ap.add_argument("--lang", choices=["vi", "en"])
    a = ap.parse_args(argv)
    project = Path(a.project)
    if not project.is_dir():
        print(f"assemble: project folder {a.project} not found", file=sys.stderr)
        return 2
    if not drafts.folder(project, a.deliverable).is_dir():
        print(f"assemble: no folder 06_writing/{a.deliverable}/ in {a.project}", file=sys.stderr)
        return 2
    try:
        return assemble(project, a.deliverable, a.final, a.lang)
    except (OSError, ValueError, KeyError, zipfile.BadZipFile) as e:
        print(f"assemble: {type(e).__name__}: {e}", file=sys.stderr)
        return 2


if __name__ == "__main__":
    sys.exit(main())
```

```python
class NetworkError(Exception):
    """--online could not reach the literature APIs (exit 2)."""


class Audit:
    def __init__(self, project: Path):
        self.project = Path(project)
        self.findings: list[dict] = []

    def rel(self, p) -> str:
        p = Path(p)
        if p.is_absolute():
            try:
                return p.resolve().relative_to(self.project.resolve()).as_posix()
            except ValueError:
                return p.as_posix()
        return p.as_posix()

    def add(self, check: str, code: str, level: str, loc: str, msg: str) -> None:
        path, sep, line = str(loc).rpartition(":")
        file, n = (path, int(line)) if sep and line.isdigit() else (str(loc), 1)
        self.findings.append({"check": check, "code": code, "level": level, "file": self.rel(file).replace("\\", "/"),
                              "line": n, "msg": msg})


def _masked(path: Path) -> str:
    return COMMENT.sub(lambda m: re.sub(r"[^\n]", " ", m.group(0)), path.read_text(encoding="utf-8-sig"))


def citation_problem(rec: dict | None) -> str | None:
    if rec is None:
        return "is not in ledgers/references.json"
    if rec.get("retracted"):
        return "is retracted"
    if rec.get("source") == "manual":
        return None if str(rec.get("seen_in") or "").strip() else "is a manual record without 'seen_in'"
    vb = str(rec.get("verified_by") or "")
    return None if vb.endswith("VERIFIED") else f"is not verified (verified_by: {vb or 'none'}); run verify_refs.py --write or replace it"


def verify_online(project: Path, files: list[Path]) -> dict:
    r = subprocess.run([sys.executable, str(ORCH / "scripts" / "verify_refs.py"), str(project), "--json",
                        "--cite", *map(str, files)], capture_output=True, text=True, encoding="utf-8", errors="replace")
    if r.returncode == 2:
        raise NetworkError(r.stderr.strip() or "verify_refs.py could not check every reference")
    return json.loads(r.stdout)


def find_phi_scan() -> Path | None:
    repo = ORCH.parent / "phi-guard" / "scripts" / "phi_scan.py"
    if repo.is_file():
        return repo
    cache = list((ORCH.parent.parent / "phi-guard").glob("*/scripts/phi_scan.py"))
    key = lambda p: tuple(int(x) for x in re.findall(r"\d+", p.parts[-3]))  # noqa: E731
    return max(cache, key=key) if cache else None


def check_citations(a: Audit, files: list[Path], online: bool) -> None:
    refs = {r.get("id"): r for r in ledgers.load_references(a.project / "ledgers" / "references.json") if isinstance(r, dict)}
    cited: set = set()
    for p in files:
        for i, line in enumerate(_masked(p).splitlines(), 1):
            for k in cite_render.cited_ids(line):
                cited.add(k)
                why = citation_problem(refs.get(k))
                if why:
                    a.add("citations", "E-REF", "block", f"{p}:{i}", f"[@{k}] {why}")
    if online and files:
        for r in verify_online(a.project, files).get("references", []):
            if r.get("id") in cited and r.get("status") not in ("VERIFIED", "MANUAL"):
                a.add("citations", "E-REF", "block", "ledgers/references.json:1",
                      f"{r['id']}: {r['status']} online ({'; '.join(r.get('notes', [])) or 'no detail'})")


def check_numbers_(a: Audit, d: str, files: list[Path]) -> None:
    path = a.project / "ledgers" / "results-ledger.json"
    results = json.loads(path.read_text(encoding="utf-8-sig")).get("results", []) if path.is_file() else []
    by_id = {r.get("id"): r for r in results if isinstance(r, dict)}
    lang = drafts.lang_of(a.project, d)
    for p in (f for f in files if drafts.results_bearing(f)):
        rendered, probs = render_results.render_text(p.read_text(encoding="utf-8-sig"), by_id, lang)
        for x in probs:
            line, _, msg = x.partition(": ")
            a.add("results numbers", "E-NUM", "block", f"{p}:{line}", msg)
        for n, tok in check_numbers.find_unmatched(rendered, results, lang):
            a.add("results numbers", "E-NUM", "block", f"{p}:{n}",
                  f"{tok} is not in the results ledger (use a {{{{R-…}}}} placeholder or <!-- not-a-result: … -->)")
        for n, sev, msg in check_numbers.check_derived(rendered, results):
            a.add("results numbers", "E-NUM", sev, f"{p}:{n}", msg)


def check_stat(a: Audit, files: list[Path]) -> None:
    texts = [p for p in files if drafts.results_bearing(p)]
    try:
        found = analysis_plan.check(a.project, texts)
    except Exception as e:  # noqa: BLE001 - InputError, ValueError, OSError, UnicodeDecodeError
        a.add("analysis declarations", "E-STAT", "block", "03_protocol/sap.md:1", f"cannot check analysis declarations: {e}")
        return
    for sev, loc, msg in found:
        loc = {"results.json": "05_analysis/output/results.json", "decisions.md": "decisions.md"}.get(loc, loc)
        a.add("analysis declarations", "E-STAT", sev, loc, msg)


def check_literature(a: Audit, files: list[Path]) -> None:
    for p in (f for f in files if drafts.is_literature(f)):
        rep = review_lint.lint(p.read_text(encoding="utf-8-sig"))
        if rep["blocking"]:
            a.add("literature synthesis", "E-LIT", "block", f"{p}:1",
                  f"written paper by paper: {len(rep['flagged'])}/{rep['paragraphs']} paragraphs; rewrite by theme")


def check_consistency(a: Audit) -> None:
    try:
        files = [p for p in consistency_audit._discover(a.project) if not p.name.endswith(".assembled.md")]
        found = consistency_audit.audit(a.project, files)
    except (OSError, ValueError) as e:
        a.add("consistency", "E-CONS", "block", "06_writing:1", f"consistency_audit could not run: {e}")
        return
    for sev, loc, msg in found:
        a.add("consistency", "E-CONS", sev, loc, msg)


def check_prose(a: Audit, files: list[Path]) -> None:
    for p in files:
        for f in lint_prose.lint_file(str(p), "auto")["findings"]:
            a.add("prose density", f["code"], f["level"], f"{p}:{f['line']}", f["message"])


def pick(project: Path, rel: str, d: str, accept) -> Path | None:
    cands = [project / rel] if (project / rel).is_file() else []
    snaps = (project / "reviews" / "rounds" / d).glob(f"r*/reviews/{Path(rel).name}")
    cands += sorted(snaps, key=lambda p: -int(p.parent.parent.name[1:]) if p.parent.parent.name[1:].isdigit() else 0)
    return next((c for c in cands if accept(c)), None)


def check_guideline(a: Audit, d: str) -> None:
    def accept(c: Path) -> bool:
        try:
            got = json.loads(c.read_text(encoding="utf-8-sig")).get("deliverable", d)
        except (ValueError, AttributeError):
            return c == a.project / "reviews" / "guideline-checklist.json"
        return got == d
    path = pick(a.project, "reviews/guideline-checklist.json", d, accept)
    if path is None:
        a.add("guideline checklist", "E-RG", "block", "reviews/guideline-checklist.json:1",
              f"no guideline checklist for the {d}: run the reporting-guideline-checker agent")
        return
    try:
        found = guideline_checklist.check(a.project, checklist_path=path)
    except guideline_checklist.NoItemList as e:
        a.add("guideline checklist", "E-RG", "warn", "reviews/guideline-checklist.json:1", f"{e}; check the guideline by hand")
        return
    except guideline_checklist.InputError as e:
        a.add("guideline checklist", "E-RG", "block", "reviews/guideline-checklist.json:1", str(e))
        return
    for sev, loc, msg in found:
        a.add("guideline checklist", "E-RG", sev, loc, msg)


def check_format(a: Audit, d: str) -> None:
    for code, level, loc, msg in assemble.format_findings(a.project, d, strict=True):
        a.add("sections and captions", code, level, loc, msg)


def check_phi(a: Audit, d: str, files: list[Path]) -> None:
    script = find_phi_scan()
    if script is None:
        a.add("identifiers", "E-PHI", "warn", f"06_writing/{d}:1", "phi-guard not found; identifiers not scanned (install phi-guard)")
        return
    assembled = drafts.folder(a.project, d) / f"{d}.assembled.md"
    targets = files + ([assembled] if assembled.is_file() else [])
    r = subprocess.run([sys.executable, str(script), "--file", *map(str, targets)], capture_output=True, text=True,
                       encoding="utf-8", errors="replace")
    if r.returncode == 2:
        a.add("identifiers", "E-PHI", "warn", f"06_writing/{d}:1", f"phi_scan.py did not run: {r.stderr.strip()}")
        return
    for line in r.stdout.splitlines():
        m = PHI_LINE.match(line.strip())
        if m:
            a.add("identifiers", "E-PHI", m.group(1), f"{m.group(2)}:{m.group(3)}", f"possible patient identifier: {m.group(4)}")


def check_reviews(a: Audit, d: str) -> None:
    current = drafts.digest(a.project, d)

    def parsed(c: Path) -> dict:
        return reviews.parse_report(c.read_text(encoding="utf-8-sig"))
    for agent, (rel, _) in reviews.REVIEWERS.items():
        path = pick(a.project, rel, d, lambda c: reviews.scores_for(parsed(c), d) is not None and d in parsed(c)["digests"])
        if path is None:
            a.add("reviewer reports", "E-REV", "block", f"{rel}:1",
                  f"no {agent} report for the {d} with a scores block and a drafts-digest line; run the agent")
        elif parsed(path)["digests"][d] != current:
            a.add("reviewer reports", "E-REV", "warn", f"{a.rel(path)}:1",
                  f"{agent} reviewed an earlier version of the {d} drafts (digest differs); rerun it if the content changed")


def run(project: Path, ds: list[str], named: str | None, online: bool) -> dict:
    a = Audit(project)
    for e in ledgers.check_project(a.project):
        a.add("ledgers", "E-REF", "block", f"ledgers/{e.split(':', 1)[0]}:1", e)
    check_consistency(a)
    hashed: dict = {}
    for d in ds:
        files = drafts.draft_files(a.project, d)
        check_citations(a, files, online)
        check_numbers_(a, d, files)
        check_stat(a, files)
        check_literature(a, files)
        check_prose(a, files)
        check_guideline(a, d)
        check_format(a, d)
        check_phi(a, d, files)
        check_reviews(a, d)
        hashed.update({a.rel(p): gate.sha256(p) for p in drafts.tracked_files(a.project, d)})
    hashed.update({rel: gate.sha256(a.project / rel) for rel in LEDGER_FILES if (a.project / rel).is_file()})
    order = {label: i for i, (label, _) in enumerate(ROWS)}
    a.findings.sort(key=lambda f: order.get(f["check"], 99))
    blocks = sum(1 for f in a.findings if f["level"] == "block")
    return {"deliverable": named or "all", "deliverables": ds, "at": dt.datetime.now().isoformat(timespec="seconds"),
            "blocks": blocks, "warns": len(a.findings) - blocks, "online": online, "files": hashed, "findings": a.findings}


def line_of(f: dict) -> str:
    return f"{f['code']} {f['level']} {f['file']}:{f['line']}: {f['msg']}"


def markdown(data: dict) -> str:
    mode = "online" if data["online"] else "offline (stored ledger statuses)"
    out = [f"# Audit: {', '.join(data['deliverables'])}", "",
           f"Date: {data['at']} · mode: {mode} · blocks: {data['blocks']} · warns: {data['warns']}", "",
           "| Check | Code | Block | Warn |", "|---|---|---|---|"]
    for label, code in ROWS:
        fs = [f for f in data["findings"] if f["check"] == label]
        b = sum(1 for f in fs if f["level"] == "block")
        out.append(f"| {label} | {code} | {b} | {len(fs) - b} |")
    out += ["", "## Findings", ""]
    out += (["```text", *map(line_of, data["findings"]), "```"] if data["findings"] else ["No findings."])
    out += ["", "G4: " + ("no block; the author may open G4 (`gate.py open . G4 --by \"<name>\"`)." if not data["blocks"]
                          else "stays closed until every block is fixed and the audit is rerun.")]
    return "\n".join(out) + "\n"


def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("project")
    ap.add_argument("deliverable", nargs="?", choices=drafts.DELIVERABLES)
    ap.add_argument("--online", action="store_true")
    ap.add_argument("--json", action="store_true")
    a = ap.parse_args(argv)
    project = Path(a.project)
    if not project.is_dir():
        print(f"audit: project folder {a.project} not found", file=sys.stderr)
        return 2
    ds = [a.deliverable] if a.deliverable else [d for d in drafts.DELIVERABLES if drafts.draft_files(project, d)]
    if not ds or not all(drafts.draft_files(project, d) for d in ds):
        print(f"audit: no drafts in 06_writing/{a.deliverable or 'thesis|manuscript'}/", file=sys.stderr)
        return 2
    try:
        data = run(project, ds, a.deliverable, a.online)
        rv = project / "reviews"
        rv.mkdir(exist_ok=True)
        with open(rv / "audit.json", "w", encoding="utf-8", newline="\n") as fh:
            fh.write(json.dumps(data, ensure_ascii=False, indent=2) + "\n")
        with open(rv / "audit.md", "w", encoding="utf-8", newline="\n") as fh:
            fh.write(markdown(data))
    except NetworkError as e:
        print(f"audit: --online failed, nothing written: {e}", file=sys.stderr)
        return 2
    except (OSError, ValueError) as e:
        print(f"audit: {type(e).__name__}: {e}", file=sys.stderr)
        return 2
    if a.json:
        print(json.dumps(data, ensure_ascii=False, indent=2))
    else:
        for f in data["findings"]:
            print(line_of(f))
        print(f"audit: {', '.join(ds)} — {data['blocks']} block, {data['warns']} warn; wrote reviews/audit.md, reviews/audit.json")
    return 1 if data["blocks"] else 0


if __name__ == "__main__":
    sys.exit(main())
```

````markdown
# Thesis writing

Writes the thesis in `project.yaml → language.output` from locked results, has it reviewed by read-only agents
and exports it only through gate G4. Detail: `${CLAUDE_PLUGIN_ROOT}/references/workflows/thesis.md`; structure:
`${CLAUDE_PLUGIN_ROOT}/references/writing/vn-thesis.md`.

## 1. Gate
Run `python "${CLAUDE_PLUGIN_ROOT}/scripts/gate.py" check . G3`. Not `G3: open` → stop: draft nothing, explain
that the thesis is written from results the author has accepted and locked, and offer the lock step. Never lock
it yourself.

## 2. Outline
Add one `section_plan` entry per thesis section to `ledgers/outline.json` (`deliverable`, `file`, `role`,
`sources`, `results`, `status` reuse|draft). Accepted chapters (Chương 1, Chương 3) are reused as they are. Ask
the author once to confirm.

## 3. Draft
Before each section read its role brief `${CLAUDE_PLUGIN_ROOT}/references/writing/roles/<role>.md`. Draft in
this thread, or brief a general-purpose subagent with the whole brief at the top of its prompt (its first line
`orchestra-role: <role>` lets the gate hook check G3). Files: `06_writing/thesis/00-dat-van-de.md`,
`ch2-methods.md`, `ch4-discussion.md`, `05-ket-luan.md`, `06-kien-nghi.md`, `90-phu-luc.md`. Numbers only as
`{{R-…}}` placeholders or with `<!-- derived: … -->`; citations only `[@id]` from `ledgers/references.json`;
captions "Bảng c.n." above tables, "Hình c.n."/"Biểu đồ c.n." in image lines. Never type a number or a
reference from memory; author-only facts go in `[[TÁC GIẢ: …]]`.

## 4. Review and revise (at most 3 rounds)
Each round dispatch in parallel `citation-verifier`, `statistical-reviewer`, `reporting-guideline-checker`,
`scientific-editor` and `consistency-auditor` (deliverable `thesis`; no role brief in their prompts), then run
`python "${CLAUDE_PLUGIN_ROOT}/scripts/worklog.py" score . thesis --round N`.
- `KEEP`: fix the findings, next round.
- `REVERT`: `python "${CLAUDE_PLUGIN_ROOT}/scripts/worklog.py" revert . thesis`; the loop stops.
- `STOP`: the loop stops.
A request for a new analysis (`NEW-ANALYSIS:`) never enters the text: it goes to `out/author-decisions.md`.

## 5. Humanize
After the last content round use the Skill tool with `prose-humanizer` on each drafted section.

## 6. Assemble, audit, export
1. `python "${CLAUDE_PLUGIN_ROOT}/scripts/assemble.py" . thesis`; fix every block.
2. `python "${CLAUDE_PLUGIN_ROOT}/scripts/audit.py" . thesis`; explain each block, fix, rerun. Never change a
   reference status or a ledger to pass.
3. 0 blocks: the author opens G4 (`gate.py open . G4 --by "<name>"`). Run it only when the author says so and
   gives the name.
4. `python "${CLAUDE_PLUGIN_ROOT}/scripts/assemble.py" . thesis --final` → `out/thesis.docx`.

## 7. Close
Draft `out/ai-use-disclosure.md` from `${CLAUDE_PLUGIN_ROOT}/references/writing/ai-disclosure.md` (never marked
final), run `python "${CLAUDE_PLUGIN_ROOT}/scripts/worklog.py" decisions .`, update `STATUS.md` row 6. Report the
paths and the open questions in the user's language.
````
