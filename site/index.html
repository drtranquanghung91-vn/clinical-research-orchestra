Clinical Research Orchestra

From bedside question to podium, with every citation and number checked.

English Tiếng Việt GitHub

What it is

Claude Code plugins that take medical students, residents, doctors and other healthcare professionals through a research project: question, evidence, protocol, ethics and CRF, analysis, thesis or manuscript, case report, systematic review, journal choice, reviewer response, poster and defence.

Scripts measure
Every number comes from a results ledger; every reference from a lookup, verified.
The author decides
Gates G1 to G4: the protocol, the results and the final export are approved by the author, never by Claude.
Patient data stays home
The phi-guard plugin blocks identifiers in outbound tool calls and de-identifies data files.

Install (Claude Code)

/plugin marketplace add drtranquanghung91-vn/clinical-research-orchestra
/plugin install phi-guard@clinical-research-orchestra
/plugin install orchestra@clinical-research-orchestra

Codex and Antigravity manifests are included; there the skills and scripts work but hooks do not, so gate and identifier checks are not automatic. See the README.

Đây là gì

Bộ plugin cho Claude Code đồng hành cùng sinh viên y, bác sĩ nội trú, bác sĩ và nhân viên y tế qua một đề tài nghiên cứu: câu hỏi, bằng chứng, đề cương, hồ sơ đạo đức và phiếu thu thập số liệu, phân tích, luận văn hoặc bài báo, báo cáo ca bệnh, tổng quan hệ thống, chọn tạp chí, trả lời phản biện, poster và bảo vệ.

Script đo, không đoán
Mọi con số lấy từ sổ kết quả; mọi tài liệu tham khảo lấy từ tra cứu và được xác minh.
Tác giả quyết định
Cổng G1 đến G4: đề cương, kết quả và bản xuất cuối do tác giả duyệt, không bao giờ do Claude.
Dữ liệu người bệnh ở lại máy
Plugin phi-guard chặn định danh trong lệnh gửi ra ngoài và ẩn danh tệp dữ liệu.

Cài đặt (Claude Code)

/plugin marketplace add drtranquanghung91-vn/clinical-research-orchestra
/plugin install phi-guard@clinical-research-orchestra
/plugin install orchestra@clinical-research-orchestra

Có sẵn manifest cho Codex và Antigravity; trên các nền tảng đó skill và script chạy được nhưng hook thì không, nên việc kiểm tra cổng và định danh không tự động. Xem README.
