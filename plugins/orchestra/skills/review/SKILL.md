Use the Skill tool with `literature-review` for the project in the current folder: mode (a) thesis Chapter 1, (b)
manuscript background, or (c) a narrative or scoping review (project type `review`). If the evidence is not yet
verified, run the Skill tool with `literature-search` first and say so. A request to pool results or rate risk of
bias goes to the Skill tool with `systematic-review`. Finish with the review_lint and verify_refs results in the
user's language.
