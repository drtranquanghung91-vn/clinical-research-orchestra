# Ethics dossier (template)

`03_protocol/ethics/dossier.md` lists every document the ethics committee will receive and its status. Statuses:
`drafted` (written by Claude, the author reviews), `author to supply`, `author reviewed`, `approved` (with the
committee's reference, written by the author). Never mark a document approved; only the author does.

| Document | File | Status | Note |
|---|---|---|---|
| Protocol | `03_protocol/protocol.md` | locked (G2) | |
| Statistical analysis plan | `03_protocol/sap.md` | locked (G2) | |
| Case report form | `03_protocol/ethics/crf.md` | drafted | built by `crf.py` |
| Data dictionary | `03_protocol/ethics/data-dictionary.csv` | drafted | built by `crf.py` |
| Information sheet and consent form | `03_protocol/ethics/consent-form.md` | drafted | or the committee's waiver decision |
| Investigator CVs, GCP certificates | | author to supply | |
| Committee application form | | author to supply | the institution's own form |
| Data management or protection statement | | `[[AUTHOR: …]]` | if the committee asks for one |

Rules, regulations and committee requirements are never stated from memory: a requirement is written only when the
author or a tool lookup gives it, with its source.
